# CPP Procedural Projects

A collection of C++ projects built using procedural programming concepts, focusing on problem-solving, functions, control flow, randomization, and user interaction through console-based applications.

## Projects

### 1. Stone, Paper, Scissors

A console-based multi-round game where the player competes against the computer.

#### Features

* Configure the number of rounds before starting the game.
* Player choices: Stone, Paper, or Scissors.
* Computer generates random choices.
* Determines the winner of each round.
* Tracks player wins, computer wins, and draws.
* Displays final game results and the overall winner.
* Supports starting a new game after completing a match.
* Uses console colors to indicate round results.

**Location:** `course 5 project 1 (stone - papier - scissor)`

**Source Code:** `course 5 project 1 (stone - papier - scissor).cpp`

---

### 2. Math Game

A console-based arithmetic quiz game that allows the player to customize the difficulty, operations, and number of questions.

#### Features

* Choose the number of questions.
* Select question difficulty:

  * Easy
  * Medium
  * Hard
  * Mixed
* Select arithmetic operations:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Mixed
* Generates questions using random numbers and operations.
* Validates the player's answers.
* Tracks correct and incorrect answers.
* Determines whether the player passes or fails.
* Displays a detailed final result.
* Supports restarting the game.

**Location:** `course 5 project 2 (math game)`

**Source Code:** `course 5 project 2 (math game).cpp`
